## 2. 발견한 오류와 조치

### E1. `/api/v1/jobs`, `/api/v1/dashboard/summary` — HTTP 500 (심각)

```
System.InvalidOperationException: The data is NULL at ordinal 2.
This method can't be called on NULL values.
```

**원인.** `ScrapeJobs.AutoListMarkets` 컬럼을 나중에 추가하면서 스키마 동기화가
nullable로 붙였다. 기존 933행 중 **931행이 NULL**. 모델은 이 속성을 NOT NULL로
알고 있어, EF가 값 변환기를 부르기 전 리더 단계에서 예외를 던졌다.
그 테이블을 읽는 화면(등록 작업 목록·대시보드)이 통째로 죽었다.

**조치.** 개별 컬럼을 땜질하지 않고 재발 자체를 막았다 —
`DbSeeder.AddMissingColumnsAsync`가 컬럼 추가 후
**모델이 NOT NULL로 아는 컬럼에 남은 NULL을 타입에 맞는 빈 값으로 메운다**
(TEXT→`''`, 숫자→`0`). 이미 NULL이 쌓인 기존 DB도 기동 시 함께 정리된다.
아울러 `Json<T>` 변환기가 빈 문자열을 "값 없음"으로 읽도록 해
새 JSON 컬럼이 추가돼도 같은 방식으로 죽지 않는다.

**검증.** 두 엔드포인트 모두 200. `/jobs` 5건 정상, 대시보드 집계 정상.

### E2. 설정 화면 — `<button>` 안에 `<button>` (HTML 구조 위반)

React 콘솔:
```
In HTML, <button> cannot be a descendant of <button>.
<button> cannot contain a nested <button>.
```

**원인.** `frontend/src/features/settings/Settings.tsx`에서 `<ShippingPlaces />`가
**저장 버튼 안쪽**에, 그것도 자격증명 스코프 반복문 내부에 들어가 있었다.
배송지 카드가 **스코프 수만큼 8번 중복 렌더**되고, 그 안의 버튼들이
바깥 저장 버튼에 중첩됐다.

**조치.** 반복문 밖으로 빼내 한 번만 렌더한다.

**검증.** 중첩 button 0개, 배송지 카드 8→1개, 저장 버튼 8개(스코프당 1개, 정상).
11개 라우트 전수 재검사에서 콘솔 오류 0.

### E3. 도매꾹 수집 실패 18건 — "가격을 찾을 수 없습니다" (DLQ)

**원인.** 실패가 아니라 **낡은 기록**이었다. 수량별 단가
(`"1+3900|100+3850"`) 파싱이 들어오기 전에 실패해 DLQ에 남았고 재처리되지 않았다.
현재 코드로 직접 호출해 보니 정상 파싱된다(3,900원 / 6,880원 등).

**조치.** 18건 전부 재처리 요청. 전량 성공.
DLQ 28건 → 10건, 수집 성공 894건 → 912건.

### E4. 쿠팡 최소 판매가 미달 — 51개 상품이 조용히 거부됨

```
ERROR: [옵션(단일옵션): 최소 설정 가격은 1000원 입니다.]
```

**원인.** 쿠팡은 1,000원 미만 판매가를 옵션 단위로 거부한다. 원가가 낮은 도매
상품에서 계산가가 900원 등으로 나온다. 카탈로그 905건 중 **51건(5.6%)**이 해당.

**조치.** `CoupangAdapter`가 전송 직전 하한(1,000원)까지 올려 보낸다 —
가격을 내리는 일은 없고, 900→1,000은 마진이 오히려 늘어난다.
**판매가가 조용히 바뀌면 안 되므로** 링크 미리보기에
"1,000원 미만 옵션 N개 — 등록 시 1,000원으로 올려 보냅니다" 경고를 띄운다.

---

### E5. 출고지 확보 실패 11건

**원인.** 별건으로 이미 수정한 출고지 우편번호 짝 맞추기 문제.
공급사 사업장 주소에 반품지 우편번호를 붙여 보내고 있었다.

**조치.** 수정된 로직으로 재평가 — **11건 중 10건 해결**.

**남은 1건.** `홈앤홈` — 공급처가 구 우편번호(`626-812`)만 제공. 5자리 신
우편번호가 아니라 어떤 마켓도 받지 않는다. 코드로 해결 불가.
→ 설정에서 쿠팡 `outbound_shipping_place_code`에 기본 출고지 코드를 넣으면 등록 가능.
