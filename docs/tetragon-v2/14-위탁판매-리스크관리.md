| 항목 | 내용 |
|---|---|
| 문서 버전 | v1.1 |
| 작성일 | 2026-08-23 |
| 적용 범위 | 국내 위탁판매(드롭시핑), 해외 구매대행, 사입 병행 셀러 전 채널 (쿠팡·스마트스토어·11번가·G마켓/옥션·롯데온·카페24 등) |

## 1. 리스크 관리 원칙과 거버넌스

### 1.1 왜 체계가 필요한가

위탁판매는 **재고 리스크를 없애는 대신 통제권을 포기하는 사업 모델**입니다. 상품을 직접 만들지도, 보관하지도, 발송하지도 않지만 **법적 책임과 플랫폼 제재는 전부 판매자(통신판매업자) 본인에게 귀속**됩니다. 이 구조적 비대칭이 위탁판매 리스크의 본질입니다.

| 구분 | 실제 통제하는 주체 | 법적·계약적 책임자 |
|---|---|---|
| 상품 제조·품질 | 제조사 | 판매자 (제조물책임 일부·표시광고 전부) |
| 상세페이지 이미지 | 도매처 / 해외 사이트 | 판매자 (저작권 침해 주체) |
| 배송·포장 | 도매처 / 물류사 | 판매자 (전자상거래법상 이행 책임) |
| 구매자 개인정보 | 판매자 → 도매처 이전 | 판매자 (개인정보처리자) |
| 재고·단가 | 도매처 | 판매자 (품절·가격 오등록 페널티) |

### 1.2 5대 운영 원칙

| 원칙 | 내용 |
|---|---|
| **P1. 사전통제 우선** | 사후 소명은 성공률이 낮고 시간이 오래 걸린다. 등록 전 30초 점검이 정지 후 30일 소명보다 싸다. |
| **P2. 증적이 곧 방어력** | 주장은 증거를 이기지 못한다. "그렇게 하고 있었다"가 아니라 "이 날짜에 이렇게 하고 있었음을 캡처했다"가 방어한다. |
| **P3. 단일 실패점 제거** | 채널 1개·도매처 1곳·계정 1개 의존은 그 자체가 최대 리스크다. |
| **P4. 회색지대는 회피** | 마진이 커도 지재권·안전인증·통관 회색지대 상품은 취급하지 않는다. 기대수익 대비 꼬리위험이 비대칭이다. |
| **P5. 기록의 표준화** | 상품·공급처·사고를 자유서술이 아니라 정해진 양식으로 기록해야 검색·소명·재발방지가 가능하다. |

### 1.3 관리 사이클

```
 ┌──────────────────────────────────────────────────────────────┐
 │                                                              │
 │   ① 식별          ② 평가          ③ 통제         ④ 모니터링   │
 │  Identify   →   Assess    →    Control   →    Monitor        │
 │  (2장)          (3장)          (5장)          (6장)          │
 │                                                              │
 │        ↑                                          ↓          │
 │        │        ⑥ 개선  ←  ⑤ 사고 대응                        │
 │        └───────  Improve  ←  Respond (7장) ──────┘           │
 │                  (분기 리뷰)                                  │
 └──────────────────────────────────────────────────────────────┘
```

### 1.4 역할 정의 (1인 셀러 ~ 소규모 팀 공통)

| 역할 | 담당 업무 | 1인 셀러의 경우 |
|---|---|---|
| **리스크 오너** | 최종 의사결정, 분기 리뷰 주재, 취급 금지 카테고리 확정 | 대표 본인 |
| **1선 (현업 통제)** | 상품 등록 전 체크리스트 실행, CS 1차 응대, 일일 알림 확인 | 대표 본인 / 등록 담당자 |
| **2선 (점검)** | 주간 샘플 감사, 금지어 DB 갱신, KRI 집계 | 대표 본인 (요일 고정: 예) 매주 월요일 오전 |
| **외부 전문가** | 지재권 경고장·형사 이슈·세무조사 대응 | 변리사·변호사·세무사 연락처 사전 확보 |

> **1인 셀러 팁** — 역할을 사람이 아니라 **시간대로 분리**하십시오. "등록하는 나"와 "점검하는 나"를 같은 시간에 두면 2선 통제는 반드시 무너집니다.

## 2. 리스크 분류체계 (Risk Taxonomy)

리스크는 코드로 관리합니다. 코드가 있어야 레지스터·KRI·사고기록부가 연결됩니다.

| 코드 | 대분류 | 중분류 | 대표 사건 |
|---|---|---|---|
| **R1** | **법률·규제** | R1-1 개인정보 | 구매자 정보의 도매처 이전, 처리방침 미비, 신고·민원 |
| | | R1-2 지식재산권 | 상표권·저작권·디자인권·특허 침해 신고, 경고장 |
| | | R1-3 전자상거래·표시광고 | 신원정보 미표시, 청약철회 거부, 과장·허위광고 |
| | | R1-4 제품안전·인증 | KC 미인증 판매, 어린이제품 오인, 리콜 대상품 |
| | | R1-5 통관·세무 | 구매대행 저가·분할 통관, 부가세 신고 오류, 무자료 매입 |
| **R2** | **플랫폼** | R2-1 계정 제재 | 노출중지 → 판매중지 → 계정정지 → 영구정지 |

| | | R2-4 정산·페널티 | 정산 보류, 배송지연 페널티, 품절 취소율 페널티 |

| | | R3-3 품질 | 불량·오배송·규격 상이, 책임 전가 |

| | | R4-2 반품·교환 | 왕복 배송비 분쟁, 반품 주소 불일치 |
| | | R4-3 평판 | 저평점 리뷰 누적, 별점 하락 |

## 3. 리스크 평가 기준

### 3.1 발생 가능성 (Likelihood)

| 등급 | 정의 | 기준 |
|---|---|---|
| 5 | 거의 확실 | 월 1회 이상 발생 |
| 4 | 높음 | 분기 1회 수준 |
| 3 | 보통 | 연 1~2회 |
| 2 | 낮음 | 2~3년에 1회 |
| 1 | 희박 | 사실상 사례 없음 |

### 3.2 영향도 (Impact)

| 등급 | 정의 | 재무 영향(예시) | 사업 영향 |
|---|---|---|---|
| 5 | 치명적 | 월매출 100% 이상 | 계정 영구정지 / 형사 입건 |
| 4 | 중대 | 월매출 30~100% | 계정정지 30일 이상 / 과징금·합의금 |
| 3 | 보통 | 월매출 10~30% | 판매중지, 다수 상품 제재 |
| 2 | 경미 | 월매출 3~10% | 단일 상품 노출중지 |
| 1 | 미미 | 월매출 3% 미만 | CS 처리로 종결 |

### 3.3 리스크 등급 매트릭스

리스크 점수 = 발생가능성 × 영향도

| 발생↓ / 영향→ | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| **5** | 5 🟡 | 10 🟠 | 15 🔴 | 20 🔴 | 25 🔴 |
| **4** | 4 🟢 | 8 🟡 | 12 🟠 | 16 🔴 | 20 🔴 |
| **3** | 3 🟢 | 6 🟡 | 9 🟠 | 12 🟠 | 15 🔴 |
| **2** | 2 🟢 | 4 🟢 | 6 🟡 | 8 🟡 | 10 🟠 |
| **1** | 1 🟢 | 2 🟢 | 3 🟢 | 4 🟢 | 5 🟡 |

### 3.4 등급별 대응 원칙

| 등급 | 점수 | 대응 원칙 | 처리 기한 |
|---|---|---|---|
| 🔴 **Critical** | 15~25 | **즉시 중단 또는 통제 완료 후 재개.** 통제 없이 운영 불가 | 즉시 ~ 3일 |
| 🟠 **High** | 9~14 | 통제 의무 적용, 주간 모니터링 | 2주 이내 |
| 🟡 **Medium** | 5~8 | 통제 권고, 월간 점검 | 1개월 이내 |
| 🟢 **Low** | 1~4 | 수용(Accept), 분기 리뷰 시 재평가 | — |

> **리스크 대응 4전략** — 회피(Avoid: 해당 카테고리 미취급) · 감소(Reduce: 통제 적용) · 전가(Transfer: 계약서·보험·공급처 부담) · 수용(Accept: 감내 후 모니터링). 위탁판매에서는 **"전가"가 계약서 없이는 작동하지 않는다**는 점이 핵심입니다.

## 5. 핵심 통제 상세

### 5.1 개인정보 리스크 통제 (R1-1)

#### 5.1.1 먼저 법적 성질을 정확히 이해할 것

위탁판매에서 구매자의 성명·주소·연락처를 도매처(또는 물류사)에 넘기는 행위는 **대체로 "제3자 제공"이 아니라 "개인정보 처리업무의 위탁"**으로 봅니다. 수탁자가 판매자의 배송 업무를 대신 처리할 뿐 **독자적 이익을 위해 그 정보를 쓰지 않기 때문**입니다. 요구되는 통제 수단이 완전히 다르므로 이 구분을 먼저 확정해야 합니다.

| 구분 | 처리 위탁 (개인정보보호법 제26조) | 제3자 제공 (제17조) |
|---|---|---|
| 판단 기준 | 위탁자의 업무 처리 목적, 수탁자의 독자적 이익 없음 | 제공받는 자의 독자적 목적·이익 존재 |
| 위탁판매 배송 | ✅ 택배사는 명확히 위탁. 도매처도 **판매자 계산으로 발송만 대행하면** 위탁 | ❌ 다만 도매처가 **자기 목적(자체 마케팅·고객DB 축적 등)으로 사용**하면 이쪽 |
| **법정 요건** | ① **문서(계약서)에 의한 위탁** ② **위탁 업무·수탁자를 정보주체가 언제든 쉽게 확인할 수 있도록 상시 공개**(실무상 개인정보 처리방침) ③ 수탁자 교육·감독 | **정보주체의 별도 동의** (제공받는 자·목적·항목·보유기간 고지) |
| 별도 동의 | **원칙적으로 불필요** | 필수 |
| 유출 시 책임 | 위탁자(판매자)가 원칙적 책임, 수탁자에 구상 가능 | 제공 이후는 제공받은 자 책임 |

> **실무 결론**
> 상세페이지 하단 동의 문구는 **"있으면 좋은 보조 장치"**이지, 그것만으로 법적 요건이 충족되지는 않습니다. **반드시 갖춰야 하는 것은 ①위수탁 계약서(문서) + ②위탁 현황의 상시 공개(처리방침)** 두 가지입니다. 동의 문구는 ③번째 안전장치로 함께 두십시오.

> ⚠️ **위탁판매에서 특히 주의할 3가지 예외**
> 1. **해외 도매처·해외 물류사에 정보를 넘기는 경우** — 국내 위탁 규정만으로 끝나지 않고 **개인정보의 국외 이전(법 제28조의8)** 규정이 별도로 적용됩니다. 1688·타오바오 도매처, 해외 배송대행지(배대지)를 쓰는 구매대행 셀러는 반드시 별도 검토가 필요합니다. (위탁·보관 목적이면 이전 관련 사항을 처리방침 공개 등으로 알림으로써 동의를 갈음할 수 있는 경로가 있으나, 요건 확인 필수)
> 2. **도매처가 그 정보로 자기 영업을 하는 경우** — 예: 도매처가 구매자에게 직접 재구매를 유도하거나 자체 DB에 축적. 이때는 **제3자 제공**이 되어 **별도 동의가 필요**하며, 계약서로 이를 금지해 두는 것이 통제 수단입니다.
> 3. **홍보·판매권유 업무를 위탁하는 경우** — 법 제26조 제3항에 따라 처리방침 공개만으로 부족하고 **정보주체에게 개별 통지**해야 합니다.

#### 5.1.2 3단 방어선

|---|---|---|---|
| **1차 (법정 요건)** | 도매처와 **개인정보 처리위탁 조항이 포함된 서면 계약** 체결 | 법 제26조 제1항 — 위탁 업무 범위, 재위탁 제한, 안전조치, 관리·감독, 손해배상 명시 | 계약서 원본(스캔) |

#### 5.1.3 계약서 소급 처리 — 올바른 방법

거래 개시 후에야 계약서를 쓰게 되는 일이 많습니다. 이때 **계약서 작성일 자체를 과거로 적어 넣는 방식(백데이팅)은 피하십시오.** 분쟁·수사 단계에서 신빙성이 무너지고, 사문서 관련 다툼으로 번질 수 있습니다.

**대신 이렇게 씁니다.**

```
제○조 (효력 발생 및 소급 적용)
① 본 계약은 양 당사자의 서명일(2026년 8월 23일)에 성립한다.
② 다만 본 계약의 효력은 양 당사자가 실제로 거래를 개시한
   2026년 3월 1일로 소급하여 적용하며, 그 기간 중 이루어진
   개인정보의 처리·이미지 사용 등 일체의 행위는 본 계약에
   따라 이루어진 것으로 본다.
```

작성일은 사실대로, **효력 개시일만 소급** — 이것이 법적으로 다툼 없는 방식이며 실무에서도 표준입니다.

| **③ 증빙 확보** | 상세페이지 텍스트만으로는 인정되지 않음. **제품 실물에 부착된 "14세 이상 사용" 등 경고 라벨 실사 사진**, KC 인증서 사본, 시험성적서를 사전 확보 |
| **④ 구매대행 특례** | 일부 품목은 개인 사용 목적 구매대행 시 인증이 면제되나, **품목별로 다르고 반복 판매는 면제 대상이 아닐 수 있음** → 국가기술표준원·관세청 기준 확인 |
| **⑤ 리콜 모니터링** | 제품안전정보센터(safetykorea.kr) 리콜 공표 월 1회 확인 |

## 7. 사고 대응 플레이북

### 7.0 골든타임 표

| 사건 | 1차 대응 기한 | 놓쳤을 때의 비용 |
|---|---|---|
| 지재권 침해 신고 접수 | **24시간** | 판매중지 → 계정 누적 제재 |
| 상품 노출중지·판매중지 | **24시간** | 노출 지수 하락, 회복에 수 주 |
| 권리자 내용증명·경고장 | **7일 (회신 기한 확인)** | 형사고소·민사소송 진행 |
| 개인정보 유출 인지 | **법정 신고 기한 확인 후 즉시** | 과징금 가중 |
| 계정정지 통보 | **당일** | 정산 보류·영구정지 |
| 공급처 연락두절 | **48시간** | 미발송 누적 → 페널티 |

### 7.1 P-1 | 지식재산권 침해 신고 접수

```
[0~2시간]  ① 신고 대상 상품 즉시 판매중지 (손실 확대 차단)
           ② 신고 내용 확인: 권리 종류(상표/저작/디자인/특허),
              권리자, 권리번호, 침해 주장 지점
[2~8시간]  ③ 사실관계 판정
              └ 침해 사실 있음 → 7.1-A 로
              └ 침해 아님(정품·권리확보·허위신고) → 7.1-B 로
[24시간 내] ④ 소명서 + 증빙 제출 (T-6)
[48시간 내] ⑤ 동일 원인 상품 전수 검색 → 일괄 수정
[1주 내]   ⑥ 금지어 DB 등록 + 사고기록부 작성 (T-8)
```

**7.1-A 침해 사실이 있는 경우**
1. 해당 상품 **삭제**(수정이 아니라 삭제 — 수정 이력이 남아 침해 기간이 특정됨)
2. 동일 브랜드·동일 이미지 사용 상품 **전수 삭제**
3. 플랫폼에 **자진 시정 완료** 사실 회신
4. 권리자로부터 직접 연락(내용증명·합의 요구)이 온 경우 → **직접 대응하지 말고 변리사·변호사 상담 후 회신.** 특히 합의금 요구 시 자백성 문구를 절대 쓰지 말 것
5. 매출 규모가 크거나 형사 고소가 언급되면 즉시 전문가 선임

**7.1-B 침해가 아닌 경우 (정품·권리 확보·허위 신고)**
- 제출 증빙: 정식 인보이스, 수입신고필증, 제조사·권리자 확인서, 유통(총판) 계약서, 이미지 사용 허락 서면, 자체 촬영 원본 파일(EXIF 포함)
- 허위 신고가 반복되면 신고 이력을 모아 플랫폼에 **어뷰징 신고**, 필요 시 업무방해 등 법적 대응 검토

### 7.2 P-2 | 개인정보 관련 민원·신고

```
[즉시]     ① 민원 내용 확인 — 유출인지, 절차 문제(동의·공개 미비)인지 구분
[2시간 내] ② 증적 3종 수집
              - 위수탁 계약서
              - 개인정보 처리방침의 위탁 현황 공개 화면 (해당 시점 캡처)
              - 상세페이지 고지 문구 캡처 (해당 시점)
[24시간 내] ③ 민원인에게 회신 — 법적 근거(제26조 위탁)와 조치 사항 안내
[유출 시]   ④ 정보주체 통지 + 관계기관 신고 (기한·요건은 시행령 확인)
              ⑤ 도매처에 사고 통보 및 재발방지 확약 요구
[1주 내]   ⑥ 처리방침 보완, 수탁자 점검
```

### 7.3 P-3 | 노출중지 / 판매중지 / 계정정지

```

              - 지재권 → 7.1
              - 안전인증(KC·어린이제품 오인) → 실물 라벨 실사 사진 + 인증서
              - 품질/안돈 → 출하검사 성적서, 자체 샘플검사 결과
              - 규격/풀필먼트 → 재측정 규격 + 측정 사진

                    소  명  서
────────────────────────────────────────────────

  · 제재 일시 :
  · 제재 대상 : (상품번호 / 옵션ID / 계정)
  · 제재 사유 : (통보문 원문 그대로 인용)

■ 1. 사실관계
  (감정 표현 없이 시간순으로 사실만 기재)
  - 2026.○.○ 해당 상품을 등록하였습니다.
  - 2026.○.○ ○○ 사유로 제재를 통보받았습니다.
  - 확인 결과, 실제 사실관계는 다음과 같습니다. ...

■ 2. 소명 근거 및 증빙
  ┌────┬──────────────────┬──────────────┐
  │ 번호│ 증빙 자료          │ 입증하는 사실  │
  ├────┼──────────────────┼──────────────┤
  │ 1  │ 수입신고필증        │ 정식 통관 사실 │
  │ 2  │ 제조사 확인서       │ 정품 공급 사실 │
  │ 3  │ 제품 라벨 실사 사진 │ 14세 이상 표기 │
  │ 4  │ 이미지 사용 허락서  │ 저작권 확보    │
  └────┴──────────────────┴──────────────┘
  (첨부 파일명을 번호와 일치시킬 것)

■ 3. 이행한 시정 조치
  - 2026.○.○ 해당 상품 판매중지 처리 완료
  - 2026.○.○ 상품명에서 ○○ 문구 삭제 완료
  - 2026.○.○ 동일 사유 상품 ○건 전수 점검 및 수정 완료

■ 4. 재발 방지 대책
  - 금지어 DB에 해당 표현 등록 및 대량등록 필터 적용
  - 신규 등록 시 등록 전 체크리스트 의무 적용
  - 월 1회 전 상품 전수 재검색 실시

■ 5. 요청 사항
  위와 같이 사실관계를 소명드리며, 시정 조치가 완료되었으므로
  판매 재개를 요청드립니다.

                              2026년 ○월 ○일
                              상호 :            (인)
────────────────────────────────────────────────
```

**작성 3원칙**
1. **사실 → 증빙 → 조치 → 재발방지** 순서를 지킬 것
2. "억울합니다", "생계가 걸려 있습니다" 같은 정서적 문장은 **1줄도 넣지 말 것**
3. 증빙 없는 주장은 아예 쓰지 말 것 (신뢰도 전체를 깎아먹음)
